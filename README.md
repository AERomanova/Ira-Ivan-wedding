# Сайт-приглашение Иры и Вани

## Итерация 8 — анимации и микровзаимодействия

В проект добавлен единый слой движения, который работает на всех страницах
и не изменяет содержательную структуру сайта.

## Новые возможности

### Переходы между страницами

- мягкое затемнение;
- силуэт зайчика;
- короткая подпись «Переходим в следующую главу…»;
- предварительная загрузка внутренних страниц при наведении;
- обычное открытие ссылок с `Ctrl`, `Cmd` и в новой вкладке не блокируется.

### Параллакс

- главные акварельные иллюстрации мягко реагируют на движение указателя;
- при прокрутке изображения слегка меняют положение;
- ветви движутся в противоположном направлении;
- на сенсорных устройствах эффект отключён.

### Свет и атмосфера

- на первых экранах появились медленные световые пылинки;
- включение гирлянд на странице праздника усиливает их свечение;
- анимации остаются деликатными и не отвлекают от текста.

### Появление элементов

- блоки входят слева, справа или через мягкое масштабирование;
- направление определяется автоматически по структуре страницы;
- существующая система `IntersectionObserver` сохранена.

### Микровзаимодействия

- карточки слегка наклоняются вслед за указателем;
- основные кнопки получили мягкий магнитный эффект;
- активный раздел отмечается в меню;
- шапка скрывается при прокрутке вниз и возвращается при прокрутке вверх;
- сверху отображается индикатор прочтения страницы с маленьким зайчиком.

### Специальные анимации

- расписание венчания заполняется по мере прокрутки;
- активный этап расписания подсвечивается;
- фигурки на интерактивной полке едва заметно «дышат»;
- при выборе зайчика появляются маленькие золотистые искры;
- сердце на экране благодарности мягко пульсирует.

## Управление движением

На страницах добавлена кнопка:

```text
Движение включено / Движение выключено
```

Выбор сохраняется в браузере.

Системная настройка:

```text
prefers-reduced-motion
```

имеет приоритет. При включённом ограничении движения параллакс,
переходы, пылинки и переключатель не показываются.

## Новые файлы

```text
css/immersive-motion.css
js/immersive-motion.js
```

Они подключены ко всем HTML-страницам.

## Локальный запуск

```bash
python -m http.server 8000
```

Откройте:

```text
http://localhost:8000
```
